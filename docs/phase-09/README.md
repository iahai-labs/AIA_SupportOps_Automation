# Phase 9 — Demo UI

Phase 9 adds a responsive, portfolio-oriented interface at:

- `/demo`

The UI demonstrates the complete SupportOps workflow:

1. create a support ticket
2. inspect AI classification, priority, and SLA
3. retrieve supporting knowledge
4. generate a grounded reply draft
5. approve or reject the draft
6. inspect automation state
7. inspect the audit timeline

## Design goals

- no frontend framework dependency
- same-origin API calls
- responsive desktop/tablet/mobile layout
- recruiter/client-friendly presentation
- demo knowledge seeding for fast walkthroughs
- no replacement of the API-first architecture

The interface is intentionally lightweight. Production-safe public demo controls, deployment,
screenshots, and final portfolio hardening are handled in later phases.
